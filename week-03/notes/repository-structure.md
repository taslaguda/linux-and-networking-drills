# Repository Structure

## Why It Is Arranged This Way

The imported-submissions folder keeps Week 1 and Week 2 work separate
from the Week 3 activity. This makes it clear what was done on the
server and what was done to organise the repository.

Each week folder keeps the same structure it had on the server:
evidence/ for raw proof, notes/ for explanation, scripts/ for any
automation. A reviewer can go straight to the folder they care about
without navigating through unrelated files.

Week 3 has its own folder because it is a different kind of work.
It is about presenting the earlier work, not repeating it.

## Why This Makes Review Easier
A reviewer can open imported-submissions and immediately see two
clearly labelled weeks of work. Each week is self-contained.
The week-03 folder tells the story of how the repository was built
and what decisions were made.
